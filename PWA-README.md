# 📱 PWA (Progressive Web App) - Інструкція

## ✅ Що додано:

### 1. **Service Worker** (`public/sw.js`)
- Офлайн підтримка
- Кешування статичних файлів
- Кешування карт Leaflet
- Стратегія "Network First, fallback to Cache"

### 2. **Web App Manifest** (`public/manifest.json`)
- Метадані додатку (назва, опис, іконки)
- Налаштування відображення (standalone mode)
- Кольорова схема

### 3. **Компонент встановлення** (`InstallPWA`)
- Банер з пропозицією встановити
- Автоматичне визначення можливості встановлення
- Анімований інтерфейс

### 4. **Іконки додатку**
- 192x192 px (для Android)
- 512x512 px (для splash screen)
- SVG версія для масштабування

---

## 🚀 Як встановити іконки:

### Метод 1: Автоматична генерація
1. Відкрийте `http://localhost:5173/create-icons.html`
2. Натисніть кнопки "Завантажити 192x192" та "Завантажити 512x512"
3. Збережіть файли як `icon-192.png` та `icon-512.png`
4. Помістіть їх у папку `public/`

### Метод 2: Використати власні іконки
1. Створіть PNG файли розміром 192x192 та 512x512
2. Назвіть їх `icon-192.png` та `icon-512.png`
3. Помістіть у папку `public/`

---

## 📲 Як встановити додаток:

### На Android (Chrome):
1. Відкрийте сайт у Chrome
2. Натисніть банер "Встановити додаток" або
3. Меню (⋮) → "Додати на головний екран"
4. Іконка з'явиться на робочому столі

### На iOS (Safari):
1. Відкрийте сайт у Safari
2. Натисніть кнопку "Поділитися" (□↑)
3. Виберіть "На екран «Домой»"
4. Натисніть "Додати"

### На Desktop (Chrome/Edge):
1. Відкрийте сайт
2. В адресній строці справа натисніть іконку встановлення (+)
3. Підтвердіть встановлення
4. Додаток з'явиться в меню програм

---

## 🔧 Як перевірити PWA:

### Chrome DevTools:
1. F12 → вкладка "Application"
2. **Service Workers** - перевірте реєстрацію
3. **Manifest** - перевірте manifest.json
4. **Cache Storage** - подивіться закешовані файли

### Lighthouse:
1. F12 → вкладка "Lighthouse"
2. Виберіть "Progressive Web App"
3. Натисніть "Generate report"
4. Оцінка повинна бути 90+

## 🎯 Особливості:

- **Автоматичне оновлення**: Service Worker перевіряє оновлення
- **Кешування**: Інтелектуальне кешування для швидкості
- **Responsive**: Працює на всіх пристроях
- **Offline-ready**: Працює без інтернету

## 🐛 Troubleshooting:

### Service Worker не реєструється:
- Перевірте, чи використовується HTTPS (або localhost)
- Очистіть кеш браузера
- Перезавантажте сторінку з Ctrl+Shift+R

### Кнопка встановлення не з'являється:
- Перевірте, чи додаток вже встановлено
- Переконайтеся, що іконки існують у public/
- Перевірте консоль на помилки

### Офлайн режим не працює:
- Перевірте реєстрацію Service Worker
- Очистіть Cache Storage
- Перезавантажте сторінку
