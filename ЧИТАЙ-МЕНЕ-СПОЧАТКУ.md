## 🆘 Все ще не працює?

### 1. Очистіть кеш на телефоні:

**Android Chrome:**
```
Налаштування → Конфіденційність → Очистити дані → Очистити
```

**iPhone Safari:**
```
Налаштування → Safari → Очистити історію та дані
```

### 2. Перевірте через DevTools (на комп'ютері):

```
1. F12 → Lighthouse → Generate report
2. Дивіться "Progressive Web App" розділ
3. Виправте помилки (якщо є)
```

### 3. Примусово оновіть Service Worker:

Відкрийте Console в браузері і виконайте:
```javascript
navigator.serviceWorker.getRegistrations().then(regs => 
  regs.forEach(reg => reg.unregister())
);
location.reload();
```

## 💡 Корисні поради:

1. **PWA промпт може не з'являтися відразу** - браузер чекає, що користувач провів на сайті 30+ секунд
2. **На iOS працює ТІЛЬКИ Safari**, не Chrome
3. **Якщо вже встановлено** - промпт не з'явиться знову (видаліть спочатку)
4. **Emulator може не показувати промпт** - тестуйте на реальному пристрої

## 📊 Вимоги для встановлення PWA:

✅ HTTPS (Vercel дає автоматично)  
✅ Valid manifest.json  
✅ Service Worker зареєстровано  
✅ Іконка 192x192 або більша  
✅ `start_url`, `name`, `display` в manifest
